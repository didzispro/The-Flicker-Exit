## 🎮 The Goal:

Escape the HOUSE.

Explore the house, find the items you need, and find a way to escape.

- AI that patrols and chases.

- Music.

- Jumpscares.

- Characters.

- Interactive doors.

- AI Teleportation.

- Turn the Flashlight On/Off.

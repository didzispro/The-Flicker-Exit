# 🚪 The-Flicker-Exit

# 💻 Development:

The game was in development, but Alpha 0.1.0 is now OUT!


# 🎮 The Goal:

Escape the HOUSE.

Explore the house, find the items you need, and find a way to escape.

AI that patrols and chases.

Item collection.

Music.

Jumpscares.

Characters.

Interactive doors.

AI Teleportation.

Turn the Flashlight On/Off.

Flickering Effects.

Difficultys System.

Random Item Spawns.

Better Visual Looks.
